# README

Para esta tarea creé una página web en HTML sobre nuestro tema de investigación: la evolución de los ratings de los K-dramas entre 2016 y 2025. Organicé la información utilizando etiquetas básicas de HTML, incorporando la crónica, imágenes de apoyo, una visualización de datos y un enlace a la fuente utilizada.

Finalmente, publiqué el sitio mediante GitHub Pages.
